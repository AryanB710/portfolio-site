- `profile.jpg` → your photo (set `photo: '/images/profile.jpg'` in src/data/profile.ts)
- `projects/` → project screenshots (set `image:` on a project in src/data/projects.ts)
- `certificates/` → certificate thumbnails (set `image:` in src/data/achievements.ts)
Use .webp or .jpg under ~200 KB each.
